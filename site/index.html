Universal GitHub

Один инструмент для файлов, видео и QR

Конвертер форматов в духе vert.sh, редактор видео и аудио на ffmpeg, скачивание видео с YouTube, TikTok, VK и ещё ~1800 сайтов, правка PDF и QR-коды. Ставится на компьютер или домашний сервер, файлы никуда не уходят.

      Как запустить полную версию

      На компьютере

      1. Поставь Python 3.10+ (на Windows отметь «Add Python to PATH»).
      2. Поставь программы. Windows: choco install ffmpeg imagemagick pandoc poppler, Ubuntu: sudo apt install ffmpeg imagemagick pandoc poppler-utils.
      3. Скачай ZIP, распакуй и запусти run.bat (Windows) или ./run.sh.
      4. Открой http://localhost:5000.

      Открыть с телефона

      1. Телефон и компьютер в одной Wi‑Fi сети.
      2. Запусти сервер открытым в сеть и с паролем: 
        # Windows (cmd)
set HOST=0.0.0.0&& set APP_PASSWORD=мой-пароль&& run.bat
# Linux / macOS
HOST=0.0.0.0 APP_PASSWORD=мой-пароль ./run.sh
      3. Узнай IP компьютера (ipconfig или ip a), например 192.168.1.20.
      4. На телефоне открой http://192.168.1.20:5000, логин любой, пароль твой. Windows может спросить про брандмауэр: разреши для частной сети.

      Домашний сервер (Docker)

      git clone https://github.com/Zaxar1231/Universal-app
cd Universal-app
# поменяй APP_PASSWORD в docker-compose.yml
docker compose up -d --build

      Внутри уже есть ffmpeg, ImageMagick, pandoc, poppler и LibreOffice.

      Почему не всё работает на этом сайте

      GitHub Pages отдаёт только статические страницы: на нём нельзя запустить ffmpeg, yt-dlp и Python. Поэтому здесь браузерные инструменты и витрина, а полная версия живёт у тебя на компьютере или сервере. Сайт можно добавить на главный экран телефона, он работает и офлайн.
