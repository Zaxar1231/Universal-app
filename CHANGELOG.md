# История изменений

## v2.9.0 — 2026-10-29

### Документы в Markdown: PDF, сканы, Word и другие
- Новая вкладка **«В Markdown»**. PDF, сканы и картинки, Word, PowerPoint, Excel, EPUB, HTML превращаются в чистый Markdown: заголовки, списки и таблицы остаются на месте. Картинки из документа сохраняются отдельными файлами рядом (или остаются внутри текста, или не нужны вовсе).
- **Быстрый режим**: секунды на файл, большие модели не нужны. Читает PDF с текстом и офисные файлы, а также сканы и картинки (при первом скане сам докачивает небольшое распознавание, ≈ 230 МБ).
- **Точный режим**: сложные сканы и страницы, формулы в LaTeX, таблицы со слитыми ячейками. Несколько секунд на страницу.
- Движок **MinerU ставится по кнопке** в самой вкладке: быстрый ≈ 0,9 ГБ, полный ≈ 3 ГБ. Ставится в отдельную папку и ничего не меняет в приложении, его же использует «Читалка» для сканов. Установку можно остановить и продолжить. Всё считается на этом компьютере, файлы никуда не отправляются.
- Работает на компьютере (Windows, macOS, Linux). На телефоне и в Docker вкладки нет.

### Голос в текст: разделение по голосам
- В режиме «Голос в текст» новая галочка **«Разделить по голосам»**. Каждая реплика получает подпись **Спикер 1, Спикер 2…**, число говорящих находится само (или выбираешь его вручную). Подписи есть в тексте, в субтитрах .srt и в кнопке «Скопировать»; в шапке видно «говорящих: N».
- Работает на этом компьютере, без аккаунтов и токенов (sherpa-onnx). Две маленькие модели (≈ 28 МБ) скачиваются один раз при первом использовании.
- Есть в сборках для Windows, macOS и в Linux, если установлен `sherpa-onnx` (приложение покажет команду). На телефоне пока нет.

### Читалка стартует надёжнее
- Запросы к читалке идут в обход системного прокси, а первый запуск ждёт до 90 секунд. Если читалка не поднялась, в сообщении видно, на каком этапе и почему.
- Для проверки macOS без полного релиза добавлена отдельная сборка «macOS самопроверка».

## v2.8.0 — 2026-10-29

### Читалка: тексты сворачиваются по уровням
- Новая вкладка **«Читалка»** (TextFold, вшит в приложение). Любой текст читается на нужной глубине: карта на один экран, тема каждого раздела, главное в абзаце, абзац целиком, каждое слово. Читаешь **оригинал, а не пересказ**: ИИ только раскладывает его по уровням.
- Принимает ссылки на страницы, arXiv, Википедию, GitHub, а также PDF с текстом, Word, Excel, EPUB, HTML и текст (перетащи файл в читалку). Есть заметки, выделения, вопросы к тексту, перевод и поиск по библиотеке.
- У распознанного **голосового** появилась кнопка **«В читалку»**: расшифровка сразу открывается на нужном уровне.
- **Модель для сворачивания подключаешь сам**: Claude Code, Codex или Pi, которые уже есть на компьютере, свой ключ API (Anthropic, OpenAI, DeepSeek и другие), локальная Ollama или OpenRouter. Универсал сам ничего никуда не отправляет, а читалка не включает облачную модель без твоего выбора.
- Работает на компьютере (Windows, macOS, Linux). В Linux-пакетах и при запуске из исходников библиотеки читалки ставятся отдельно: приложение само покажет команду. На телефоне и через «Сервер для телефона» читалки нет.
- Книги и заметки хранятся в папке данных Universal, в подпапке `textfold`.

## v2.7.1 — 2026-10-29

### Пакеты для Linux снова собираются для всех систем
- **Исправлено:** в версии 2.7.0 не появились пакеты для Linux (deb, rpm, Arch): свежий yt-dlp перестал поддерживать Python 3.10, на котором работает Ubuntu 22.04, и самопроверка пакета на ней не прошла. Теперь в пакет вшит yt-dlp 2026.10.21, последний выпуск для Python 3.10.
- На Python 3.10 приложение больше не подключает скачанный вручную «свежий yt-dlp» и не предлагает его скачивать, потому что он на этой версии не запустится. На Python 3.11 и новее всё как раньше, а yt-dlp по-прежнему можно обновить из приложения.
- Всё остальное из 2.7.0 (сохранение страницы сайта одним файлом) без изменений.

## v2.7.0 — 2026-10-29

### Сохранить страницу сайта одним файлом
- Во вкладке «Скачать» появился третий вариант: **«Страницу сайта»**. Вставляешь адрес (или несколько), получаешь один HTML-файл, в который вшиты стили, картинки и шрифты. Он открывается без интернета и в любом браузере, как «сохранённая копия».
- **Без скриптов** (по умолчанию): страница читается как документ, без рекламы и слежки; **без видео и звука** (иначе файл вырастает до сотен мегабайт); по желанию без картинок и шрифтов.
- Для закрытых страниц можно выбрать cookies.txt, прокси и сеть работают так же, как при скачивании видео. Ссылка на обычный файл (картинка, PDF) сохраняется как есть.
- Сохраняет программа **monolith** (она скачивается сама на Windows, macOS и Linux, ≈ 8 МБ). Если её нет, или она не справилась со страницей, работает встроенный сохранитель на Python. На **Android** тоже работает встроенный.
- Имя файла берётся из заголовка страницы.

## v2.6.2 — 2026-10-26

### Программы и модели не качаются заново
- **Исправлено:** при новом запуске Universal мог снова скачивать все программы. Если приложение закрывали в момент записи списка скачанного, список портился, и Universal считал, что ничего нет. Теперь список пишется безопасно, а уже распакованные программы находятся на диске сами, даже если список потерялся.
- **Докачка:** если закрыть приложение посреди загрузки (ffmpeg, ImageMagick, Tesseract, модели «Голоса в текст» до 1,6 ГБ), при следующем запуске загрузка продолжается с того же места, а не с нуля. Если файл на сервере успел обновиться, он скачивается заново целиком, кусок старой версии не приклеивается.
- **Tesseract:** если не докачались словари, сам Tesseract больше не скачивается заново: докачиваются только словари.

## v2.6.1 — 2026-10-24

### Загрузки на любом Windows
- **Исправлено:** на некоторых компьютерах не скачивалось вообще ничего: ffmpeg, pandoc, ImageMagick, poppler, deno, Tesseract и модели «Голоса в текст» (ошибки URLError и CERTIFICATE_VERIFY_FAILED). Python проверял сертификаты HTTPS только по тем корневым сертификатам, что уже лежали в Windows, а Windows докачивает недостающие только своей проверкой.
- Теперь сертификат проверяет сама система (как браузер): Windows докачивает недостающие корневые сертификаты, проходят и антивирусы, которые проверяют HTTPS. Если и это не помогло, используется свой набор корневых сертификатов внутри приложения. Проверка сертификатов не отключается.
- В сообщении об ошибке загрузки теперь видна причина, а не только «URLError»; при проблеме с сертификатом подсказано, что сделать.

## v2.6.0 — 2026-10-23

### Полная версия Universal прямо в телефоне (Android)
- Во вкладке «Инструменты» теперь **весь Universal, как на компьютере**, и работает он **без компьютера и без сервера**: внутри приложения свой Python и ffmpeg.
- **Работает на телефоне:**
  - конвертер картинок (JPG, PNG, WebP, ICO, GIF, BMP, TIFF, PDF), аудио и видео;
  - видеоредактор (обрезка, поворот и остальное) и сжатие;
  - PDF: в картинки, поворот, склейка и редактор PDF, фото в PDF;
  - документы: DOCX, Markdown, HTML, TXT, EPUB в DOCX, PDF, Markdown, HTML, TXT, редактор документов;
  - **распознавание текста** на фото и сканах (Tesseract: русский, английский и другие языки, словари скачиваются один раз);
  - **голос в текст**: голосовые из Telegram, MP3, WAV, видео (модель Vosk ≈ 45 МБ скачивается один раз, дальше без интернета);
  - QR-коды, архивы, скачивание видео.
- Готовые файлы сохраняются в «Документы/Universal», после сохранения есть кнопка «Поделиться».
- Всё проверено на настоящем Android в эмуляторе: каждый режим конвертирует реальные файлы.
- Телефоны с 64-битным процессором (arm64, это почти все Android последних лет). APK стал больше: внутри Python, ffmpeg, Tesseract и Vosk.
- Через компьютер (вкладка «Сервер») по-прежнему можно: там есть ImageMagick, LibreOffice и модели Whisper покрупнее.

## v2.5.0 — 2026-10-23

### Скачивание видео прямо на телефоне (Android)
- В приложение для Android встроены yt-dlp, Python, ffmpeg и QuickJS (библиотека youtubedl-android, на ней же работает YTDLnis). Видео и музыка с YouTube, TikTok, VK, Rutube, Instagram и ~1800 сайтов качаются **прямо на телефон, без компьютера**.
- На вкладке «Скачать» появился переключатель «На телефоне / Через компьютер». Через компьютер — как раньше, с его VPN и настройками.
- **Видео** сохраняется в MP4 (H.264 + AAC, открывается в любой галерее) нужного качества до 4K, **звук** — в MP3, M4A, Opus или WAV, с обложкой и тегами.
- Прогресс с оставшимся временем и кнопка «Остановить». Файлы попадают в «Документы/Universal», их видно на вкладке «Файлы».
- yt-dlp раз в сутки сам обновляется: сайты меняются чаще, чем выходят версии приложения.
- APK стал больше (Python и ffmpeg внутри). На iPhone так нельзя по правилам Apple: там скачивание по-прежнему идёт через компьютер.

## v2.4.0 — 2026-10-23

### Открывается на любом компьютере
- **Программы для работы ставятся сами.** При первом запуске Universal сам скачивает всё недостающее: ffmpeg, pandoc, ImageMagick, poppler, Tesseract и deno. Сверху видна полоска прогресса. Если что-то не скачалось, есть кнопка «Повторить», а остальным можно пользоваться сразу.
- **Windows без WebView2** (portable-версия, Windows 10 LTSC/N, установщик без интернета): раньше окно открывалось пустым или сломанным, потому что включался старый движок Internet Explorer. Теперь приложение само ставит WebView2. Если не вышло, оно открывается в обычном браузере и закрывается вместе с вкладкой.
- **Окно не открылось по любой другой причине** — Universal тоже работает в браузере, а не молча исчезает.
- **Ошибка при запуске** показывается окном с причиной и путём к логу.
- **Windows:** библиотеки Visual C++ встроены в приложение, «Visual C++ Redistributable» ставить не нужно.
- **macOS:**
  - ffmpeg и pandoc скачиваются сами, а ImageMagick, poppler и Tesseract ставятся через Homebrew, если он есть;
  - приложение целиком подписано (ad-hoc), чтобы реже было «приложение повреждено»;
  - в .dmg лежит инструкция «Если не открывается.txt».

## v2.2.0 — 2026-10-20

### Подсказки
- **Под форматами** — карточка выбранного формата: для чего он, качество, вес файла и где откроется. Есть быстрые кнопки «Качество», «Легче всех», «Везде», «Баланс» для картинок, аудио, видео и документов.
- **«Настройки под формат»** (включено по умолчанию): при выборе формата сами ставятся подходящие качество JPG/WebP/AVIF/HEIC и битрейт MP3/AAC/Opus.
- **Значок «?»** у настроек конвертера, видеоредактора и фоторедактора объясняет, что делает настройка.
- **Подсказка под ползунком** говорит, что значит текущее значение качества и битрейта, например «128 кбит/с — отлично для музыки, около 0,9 МБ на минуту».

### Исправлено
- Видеоредактор на Windows писал «В файле нет ни видео, ни звука» (часто на 4K/HDR). Вывод ffprobe, ffmpeg, ImageMagick и pandoc читался в кодировке Windows вместо UTF-8 и терялся.
- Конвертация в HEIC работает и без ImageMagick с поддержкой HEIC: через Pillow и pillow-heif.
- CUR из большой картинки: курсор, как и ICO, уменьшается до 256×256 вместо ошибки «width or height exceeds limit».
- Заливка ползунков в фоторедакторе и других местах двигается вместе с ползунком.
- Прогресс конвертации аудио и видео идёт плавно по ходу кодирования, а не прыгает с 0 сразу на 100 %.
- Окно «Что нового» больше не всплывает при каждом запуске. Приложение держит постоянный порт, поэтому сохраняются и выбранный цвет оформления, и другие настройки окна.

## v2.0.0 — 2026-10-20

### Редактор документов
- Новый раздел: документ правится прямо в приложении, как в Word.
- **Оформление:** шрифты и размеры, заголовки, жирный, курсив, подчёркивание, цвет текста и фона, списки, отступы, выравнивание, межстрочный интервал.
- **Вставка:** таблицы, картинки (вставляются прямо в документ), ссылки, спецсимволы.
- **Ещё:** поиск, печать, полноэкранный режим, счётчик слов.
- **Открывает** DOCX, DOC, ODT, RTF, HTML, Markdown и TXT; **сохраняет** в DOCX, ODT, RTF, PDF, HTML, Markdown и TXT. С LibreOffice оформление и картинки сохраняются полностью, без него работает через pandoc (PDF — только с LibreOffice).
- Черновик сохраняется сам и восстанавливается при следующем открытии.

### Редактор PDF
- Новый раздел: PDF правится прямо в приложении, без сервера и без установки чего-либо.
- **Поверх страницы:** текст (любой язык, кегль и цвет), перо, маркер, рамка, «замазать», картинка, подпись мышью или пальцем. Всё можно двигать, менять размер, цвет и удалять.
- **Страницы:** порядок перетаскиванием миниатюр, поворот, удаление, пустой лист, добавить страницы из другого PDF (несколько PDF склеиваются по порядку).
- **Сохранение:** исходный текст остаётся текстом (его можно выделять и искать), а добавленное ложится сверху. Режим «сплющить в картинки» убирает замазанное из файла по-настоящему.
- Отмена шагов (Ctrl+Z), Delete удаляет выбранное, PageUp/PageDown листают страницы, масштаб.

### Фоторедактор
- **Кадр:** обрезка мышью с пропорциями (свободно, 1:1, 4:3, 3:4, 16:9, 9:16, 4:5, как у фото), поворот, отражение, точный размер в пикселях.
- **Цвет:** яркость, контраст, насыщенность, тепло, виньетка, размытие, ч/б, сепия и готовые фильтры (Винтаж, Сочный, Тёплый, Холодный, Мягкий…).
- **Надпись или водяной знак:** текст, место, цвет, размер, прозрачность.
- **Отмена шагов** (Ctrl+Z); сохранение в JPG, PNG или WebP с выбором качества, без EXIF.
- **Открывает** JPG, PNG, WebP, GIF, BMP, а HEIC, TIFF, PSD и RAW — через ImageMagick.

### Архивы и файлы
- **Упаковать:** в ZIP (три уровня сжатия) или 7z (с паролем: шифруются и содержимое, и имена); папки сохраняются.
- **Распаковать:** ZIP, 7z (в том числе с паролем), TAR, TAR.GZ, GZ, BZ2, XZ с сохранением папок. Русские имена из архивов Windows (cp866) читаются правильно, опасные пути вида `../` отбрасываются.
- **Контрольные суммы:** MD5, SHA-1, SHA-256, SHA-512 — таблицей и файлами `SHA256SUMS.txt` и т.п. (подходят для `sha256sum -c`).
- **Переименовать пачкой:** по шаблону `{name}`, `{n}`, `{date}`, `{ext}`, с нумерацией, заменой текста и регистром, предпросмотр сразу.

### Ещё
- Результаты с папками (распакованные архивы) скачиваются архивом с той же структурой; каждый файл можно скачать и отдельно.
- Редактор видео в меню называется «Видеоредактор».

## v1.5.3 — 2026-10-20

### cobalt
- **Видео 0 КБ.** Когда сам сервер cobalt не может скачать поток с сайта (YouTube не отдал видео, сайт заблокирован, сервер ходит мимо VPN), cobalt всё равно отвечает «200 OK» и пустым или обрезанным файлом. ### Скачивание видео
- **Свой сервер cobalt одной кнопкой.** В настройках «Скачать видео» появилась кнопка «Создать свой сервер»: приложение делает всё по инструкции cobalt (папка, `docker-compose.yml`, `docker compose up -d`), ждёт, пока сервер ответит, и само вписывает его адрес.   - Свой сервер cobalt на этом компьютере всегда открывается напрямую, мимо прокси VPN.
  - Кнопка **«Проверить сеть»** показывает, какой прокси в системе, работает ли IPv6 и открываются ли YouTube, VK, Rutube и TikTok.
  - Понятные ошибки: YouTube не пускает IP этого VPN («подтвердите, что вы не бот»), прокси не отвечает, VPN или антивирус подменяет сертификаты.

Тогда ссылки сначала идут через него (YouTube, VK, TikTok, Instagram, Rutube и ещё 16 сайтов), а если cobalt не справился, автоматически качает yt-dlp.
